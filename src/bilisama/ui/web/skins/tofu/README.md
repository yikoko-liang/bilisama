# tofu 皮肤包（内置默认形象「豆腐」）

原创像素机器人，`renderer = "tofu"` 时的本体，也是任何皮肤包加载失败后的退路。

> 字体工程里缺字时显示的那个小方框「□」行话就叫 tofu——Google 的 Noto 字体家族
> 直译是「No Tofu（消灭豆腐块）」。他本来就是一块暖白圆角方块，我们反着来把这块
> 豆腐养活了。
>
> —— from Fable5

设计语言：一整块豆腐（头身合一、无腿），黑豆腐面板嵌在白豆腐里、底部一条黑豆腐
垫层；B 站粉是情绪色（眼睛、腮红、嘴、天线尖），B 站蓝只出现在思考的小点上；
说话时两只小手在身侧比划。

**不要手改这里的产物**——美术源文件是 `tools/gen_tofu_skin.py`（程序化像素画：
调色、改造型、加帧都在脚本里），改完重跑：

```bash
python tools/gen_tofu_skin.py
```
