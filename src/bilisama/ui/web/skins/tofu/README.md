# tofu 皮肤包（内置默认形象「豆腐」）

原创像素机器人，`renderer = "tofu"` 时的本体，也是任何皮肤包加载失败后的退路。

名字来自字体工程的行话：字库里缺字时显示的那个小方框「□」就叫 tofu——Google
的 Noto 字体家族直译是「No Tofu（消灭豆腐块）」。我们反着来，把这块豆腐养活了：
给了他脸、两根天线和 B 站粉的辉光。

**不要手改这里的产物**——美术源文件是 `tools/gen_tofu_skin.py`（程序化像素画：
调色、改造型、加帧都在脚本里），改完重跑：

```bash
python tools/gen_tofu_skin.py
```
